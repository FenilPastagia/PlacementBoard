# Placement Board - College Placement Management System

An Object-Oriented C++ project developed for MCA Semester 1.

## OOP Concepts Demonstrated
- **Inheritance:** `admin`, `student`, and `company` classes inherit from base `User` class.
- **Polymorphism:** Virtual `login()` function overridden across all derived modules.
- **Encapsulation:** Private data members with public access functions.
- **File Persistence:** Text file databases for records management (`data/`).
